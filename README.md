# Digital Team Portfolio

A responsive single-page portfolio adapted from **Digital Workflow Presentation V3**. The site presents the Digital Team story, Digital Coordinator role, capabilities, training, automation, data visualization, connected workflows and the Munich RE Taboo Zone case study.

## Run locally

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000`.

## Production build

```bash
pnpm build
pnpm start
```

## Main content files

- `app/page.tsx` — page structure and source-based English copy
- `app/globals.css` — responsive visual system
- `public/images/` — selected visuals extracted from the presentation, plus the social preview card

The site does not add performance claims or project metrics beyond the source presentation.
